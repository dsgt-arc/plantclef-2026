  Why none is a good starting point

  The CrossRegionTransformer uses attention pooling — it already has the capacity to learn "ignore this tile" by
  assigning near-zero attention weight. Pre-filtering with fixed_k is essentially doing the model's job for it with a
  hard cutoff. Starting with none tells you whether the model can handle tile selection itself, which is the stronger
  result.

  The main risk with none is that noisy tiles might slow convergence, but with 15 epochs and attention masking, this is
  unlikely to be a dealbreaker for an initial signal.
